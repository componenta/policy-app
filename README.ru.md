# Интеграция Policy с приложением

Пакет устарел. Регистрируйте `Componenta\Policy\ConfigProvider` из
`componenta/policy` напрямую и удалите `componenta/policy-app` из зависимостей.

Во всех окружениях политики создаются из нативных атрибутов. Каждый вызов
провайдера заново создаёт атрибутные политики и вызывает настроенные фабрики.
Явно зарегистрированные объекты политик сохраняют заданное приложением время жизни.

Дисковая компиляция удалена. Удалите `compiled_policies`,
`compiled_policies_file` и `compiled_policies_strict` из настроек policy.
Старые артефакты не используются. Команда `app:build` не регистрирует билдер policy.

Пустой прежний `Componenta\Policy\App\ConfigProvider` остаётся доступен,
чтобы существующий сгенерированный список провайдеров можно было обновить при миграции.
